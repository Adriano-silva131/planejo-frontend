# planejo-frontend

App web do Planejo (planejoai.com) — SPA em React + TypeScript + Vite.

## Stack

- React 19, React Router, TanStack Query
- Tailwind CSS v4, ícones com lucide-react
- Oxlint

Mantenha as dependências enxutas: só adicione uma biblioteca quando uma tela precisar dela.

## Rodando

```bash
cp .env.example .env
npm install
npm run dev
```
